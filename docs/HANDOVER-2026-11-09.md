- **Filter keytrack fixed**: was `(kt-64)/64` (raw 64 -> 0.0 = "-200%" on the Iridium!). Blofeld
  keytrack is offset-binary 0..127 = -200%..+196% (64 = 0%), Iridium norm 0..1 = -200%..+200%
  (0.5 = 0%) -> now `norm(raw)`. Don-Solaris anchors: 64 -> 0.5000, 96 -> 0.7500.
  **General rule: Blofeld bipolar = offset binary (64=0), NO 2's complement** (SysEx doc);
  `amt_bipolar` was correct — only keytrack had the wrong formula.
- **Wavetable mapped** (A019 Tines DocT): OscNType=Wavetable + `OscN WavetableTable`
  (bridge, e.g. MalletSyn -> 2 "Mallet Syn"; was template default 0 "Resonant") +
  `WavetablePosition` (from Blofeld pulsewidth/"PW/Wave") + `WavetableBrilliance`.
  Mod destination "On PW/Wave" -> MatrixDst `WTn Position` (11/39/67)
  or `WFn Warp` (18/46/74), v14.
  Re-import of A019 needed (and all others, since keytrack changed everywhere).
- **Tremolo bug (A022 ModWheelOrgDrive) SOLVED — two causes**: (1) the key in the template
  is `Lfo1Speed`, not `LFO1Speed` — our key was ignored by the device, the LFO ran on
  template default 0.5 (fast). (2) Blofeld LFO speed with Sync=1 is a clock index
  (4.6: raw 14 = 512 bars = static), but was mapped as free speed. Now:
  `LfoN Sync` + `LfoN SyncRatio` (beats = bars*4 -> next index, 512 bars -> 2048 beats
  -> index 0 = 1024 = slowest) + `LfoN Speed` only when free. Ringmod key corrected
  (`RingModOsc1ToOsc2`). Measured: tremolo depth Iridium 38 dB @1.1 Hz vs Blofeld 19 dB
  @0.55 Hz (before fix). **Renewed re-import of all 9 needed.**
