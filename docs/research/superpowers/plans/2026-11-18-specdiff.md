# specdiff (Interpretation des Spektral-Diffs A|B|ΔdB) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `bloridium/specdiff.py` + CLI `bloridium specdiff` – strukturierte Interpretation des ΔdB-Spektral-Diffs (severity/spread/temporal/bands) via lokalem Vision-Decision-Model (d1-omni:2b default, gemma4 optional) mit deterministischem numpy-DSP-Fallback; landet als `result.specdiff` + `result.specdiff_score` im `sim_log.jsonl`.

**Architecture:** DSP-Kern (`diff_matrix`/`dsp_features`/`classify_dsp` auf `sim.features`-log_spec, Pad-Spalten = 0) liefert numerische Merkmale + Fallback-Labels + Score; Vision-Backends (`SystemOneBackend` via `/v1/systemone` choice/noul, `OllamaChatBackend` via `/api/chat` think:false) liefern die Labels auf dem gerenderten PNG. `interpret_pair` merged beides (`source: vision|dsp`). CLI: Einzel (`--wav A B`) + Batch (`--log … --recordings … --write` über `ab_<LOC>_<ts>_n<note>[_w<pct>]_*.wav`). Plus `--specdiff`-Flag in `sim compare` und `scripts/sim_checkpoint.py`.

**Tech Stack:** Python 3.10, numpy only im Kern; `requests` (schon Dep, wie D1ProfileBackend), PIL fürs PNG, stdlib json/urllib; ollama lokal optional. pytest>=8.

**Spec:** `docs/research/superpowers/specs/2026-11-18-specdiff-design.md` (enthält Spike-Ergebnisse 2026-11-18: d1-omni systemone ~3 s/Aufruf mit `criteria`-Dict, gemma4 braucht `think:false`, ~64 s/Aufruf, PNG-Orientierung LOW-oben im State-Text).

## Global Constraints

- numpy-only Kern, kein scipy (in Env defekt); PIL nur fürs Render; ollama optional – bei Fehlen WARNING + DSP-Fallback, nie Absturz.
- Determinismus: DSP 100 %; Vision temperature 0. Score immer numerisch aus DSP: `specdiff_score = clip(100 - 4*severity_db, 0, 100)`, severity_db = median |Δ| über aktive Bins.
- Schwellen (Konstanten im Modul): severity light < 2 dB, medium < 6 dB (median |Δ| über aktive Bins, aktiv = peak−40 dB); spread even wenn Anteil |Δ|>3 dB ≥ 0.25; bands betroffen wenn Mittel |Δ| im Bereich > 3 dB (low < 250 Hz, mid 250–2000 Hz, high > 2000 Hz); temporal: |Gesamt-Slope| > 1.5 dB → increasing/decreasing, sonst Autokorrelation lag 2..n/2 r > 0.5 → periodical, sonst Peaks (Prominenz > 3 dB): 0 → even, 1 → single, >1 → multiple.
- `combined` bleibt unangetastet; specdiff_score separat. Pad-Spalten nie als Fehler werten.
- Tests offline (TDD), monkeypatchte HTTP-Antworten für Vision, kein Live-MIDI. `python3 -m pytest tests/ -q`. Deutsch Doku/Commits. Commits direkt auf main, push origin main (autorisiert).

## Review Focus

1. **Pad-Spalten** (unterschiedliche Länge A/B) dürfen weder DSP noch PNG als Fehler werten. (Task 1 Test: ungleiche Längen → Pad = 0, kein Label-Shift)
2. **Vision-Ausfall** (ollama down, HTTP-Fehler, unparsebares JSON) → `source: "dsp"` + WARNING, Ergebnis trotzdem vollständig. (Task 2 Tests)
3. **JSON-Extrakt** aus gemma4-Antwort robust gegen Markdown-Fences/Prosa. (Task 2 Test)
4. **Batch `--write`** darf JSONL nicht zerstören: nur Zeilen mit passendem `ts` anfassen, Rest byte-identisch; ohne `--write` nur stdout. (Task 3 Tests)
5. **Stille/zu kurze Signale** → ValueError wie `sim.features` propagieren bzw. sauber als Fehler, kein Crash. (Task 1/3 Tests)

- `diff_matrix(x_a, x_b, sr) -> dict` mit `{"delta": (n_bands,n_frames) dB, "band_edges", "active": bool-Maske, "floor_db"}`; längere Seite gepadded, Pad-Spalten delta=0 und active=False; active = max(sa,sb) >= floor_db, floor_db = min(sa.min(), sb.min()) + 6 dB.
- `dsp_features(delta, band_edges, active) -> dict`: `severity_db` (Mittel |Δ| über active), `spread_frac` (Anteil active mit |Δ|>SPREAD_THR_DB), `temporal`: Serie e(t) + `slope_total_db`, `acorr_best` (lag, r), `n_peaks`; `band_mean_db`: {"low","mid","high"} Mittel |Δ| über active im jeweiligen Frequenzbereich (aus band_edges).
- `classify_dsp(feat) -> dict`: `{"severity","spread","temporal","bands": [...], "summary"}` nach Schwellen oben; summary als Template-Satz.
- `specdiff_score(severity_db) -> float`: clip(100 − 10·severity_db, 0, 100).
