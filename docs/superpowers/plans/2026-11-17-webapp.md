# Bloridium Web-App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kleine Flask-Web-App im Podman-Container (Debian-Server): Blofeld-`.syx`-Upload -> Iridium-`.qpat`-Konvertierung -> ZIP-Download + deterministische Match-Schaetzung (0-100) pro Sound.

**Architecture:** `webapp/app.py` (Flask-Routen) + `webapp/convert.py` (Parse/Konvert/ZIP, laedt die pure-python-`bloridium/`-Module per Dateipfad, damit das Image kein numpy/mido braucht) + `webapp/matching.py` (deterministischer Score-Platzhalter). Containerfile mit Build-Kontext Repo-Root kopiert nur die 4 Core-Module + qpat-Template.

**Tech Stack:** Python 3.12, Flask + gunicorn, Podman (`python:3.12-slim-bookworm`, `webapp/Containerfile`), pytest fuer Tests.

**Spec:** `docs/superpowers/specs/2026-11-17-webapp-design.md`

## Global Constraints
- Container enthaelt NICHT numpy/mido/python-rtmidi; Core-Module werden per `importlib` aus `BLORIDIUM_CORE_DIR` (Docker: `/app/core`) geladen, lokal aus `bloridium/`
- Konvertierung byte-identisch zur Offline-Pipeline: `qpat.load(TEMPLATE)` + `qpat_map.blofeld_to_qpat_params` + `qpat_map.apply_to_template` + `qpat.build_qpat(..., version=qpat.PRESET_VERSION)`
- ZIP-Dateinamen stick-freundlich: `<LOC>_<Name>.qpat` + `MANIFEST.md` + `report.json`
- `MAX_CONTENT_LENGTH` = 8 MB; Artefakte in `DATA_DIR/<token>/`, TTL via `DATA_TTL_HOURS` (Default 24)
- Matching v0 ist rein deterministisch (gleicher Dump -> gleicher Score) und schreibt Feature-Vektor (params + unmapped + mapped) nach `report.json`

## Review Focus
- Fremd-Nachrichten in `.syx` (nicht SNDD) duerfen nicht crashen, sondern landen als `skipped`
- Checksum-fehlerhafte SNDD -> `errors`, nicht ZIP
- Leere/kaputte Uploads -> saubere 400-Fehlermeldung statt Traceback
- Token-Pfade muessen gegen Path-Traversal gehaelscht sein (nur `[0-9a-f]{32}`)
- Score immer in 0..100 und deterministisch

### Task 1: Core-Loader + Convert-Pipeline (`webapp/convert.py`)

**Files:**
- Create: `webapp/convert.py`
- Test: `tests/test_webapp.py` (Test 1-3)

**Interfaces:**
- `load_core() -> SimpleNamespace(blofeld_dump, qpat, qpat_map, waldorf)` – laedt Module per importlib aus `BLORIDIUM_CORE_DIR` / `webapp/core` / `<repo>/bloridium`
- `default_template_path() -> Path` – `BLORIDIUM_TEMPLATE` / `webapp/template_waveform.qpat` / `<repo>/docs/refs/qpat/template_waveform.qpat`
- `split_sysex_messages(data: bytes) -> list[bytes]` – zerlegt an F0..F7; ohne F0 -> `[data]`
- `parse_upload(filename: str, data: bytes) -> dict` – `.hex` dekodieren; pro Nachricht `blofeld_dump.parse_sndd`, nur cmd 0x10; Rueckgabe `{"sounds": [parsed...], "errors": [{index, error}], "skipped": int}`; chk_ok=False -> errors
- `location_str(bb: int, nn: int) -> str` – wie `workflow.location_str`
- `convert_sound(core, template, parsed, loc) -> dict` – `{"loc", "name", "qpat_bytes", "mapped", "unmapped"}`
- `safe_name(name) -> str` – wie `workflow.convert_parsed` (alnum/-/_/space)
- `process_upload(filename, data, data_dir) -> dict` – parst, konvertiert, baut ZIP (BytesIO: `<LOC>_<safe>.qpat` + `MANIFEST.md` + `report.json`) und schreibt `data_dir/<token>/{result.zip,report.json}`; Rueckgabe report inkl. `token`, `zip_name`, `sounds: [{location,name,category,mapped,unmapped,score,score_details,features}]`
