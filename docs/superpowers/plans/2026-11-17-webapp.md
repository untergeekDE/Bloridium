# Bloridium web app Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Small Flask web app in a Podman container (Debian server): upload a Blofeld `.syx` -> convert to Iridium `.qpat` -> ZIP download + deterministic match estimate (0-100) per sound.

**Architecture:** `webapp/app.py` (Flask routes) + `webapp/convert.py` (parse/convert/ZIP, loads the pure-python `bloridium/` modules via file path so the image needs no numpy/mido) + `webapp/matching.py` (deterministic score placeholder). The Containerfile with build context repo root copies only the 4 core modules + the qpat template.

**Tech Stack:** Python 3.12, Flask + gunicorn, Podman (`python:3.12-slim-bookworm`, `webapp/Containerfile`), pytest for tests.

**Spec:** `docs/superpowers/specs/2026-11-17-webapp-design.md`

## Global Constraints
- The container does NOT contain numpy/mido/python-rtmidi; the core modules are loaded via `importlib` from `BLORIDIUM_CORE_DIR` (Docker: `/app/core`), locally from `bloridium/`
- Conversion byte-identical to the offline pipeline: `qpat.load(TEMPLATE)` + `qpat_map.blofeld_to_qpat_params` + `qpat_map.apply_to_template` + `qpat.build_qpat(..., version=qpat.PRESET_VERSION)`
- ZIP file names stick-friendly: `<LOC>_<Name>.qpat` + `MANIFEST.md` + `report.json`
- `MAX_CONTENT_LENGTH` = 8 MB; artifacts in `DATA_DIR/<token>/`, TTL via `DATA_TTL_HOURS` (default 24)
- Matching v0 is purely deterministic (same dump -> same score) and writes the feature vector (params + unmapped + mapped) to `report.json`

## Review Focus
- Foreign messages in `.syx` (not SNDD) must not crash, but land as `skipped`
- Checksum-broken SNDD -> `errors`, not the ZIP
- Empty/broken uploads -> clean 400 error message instead of a traceback
- Token paths must be sanitized against path traversal (only `[0-9a-f]{32}`)
- Score always in 0..100 and deterministic

### Task 1: Core loader + convert pipeline (`webapp/convert.py`)

**Files:**
- Create: `webapp/convert.py`
- Test: `tests/test_webapp.py` (tests 1-3)

**Interfaces:**
- `load_core() -> SimpleNamespace(blofeld_dump, qpat, qpat_map, waldorf)` – loads the modules via importlib from `BLORIDIUM_CORE_DIR` / `webapp/core` / `<repo>/bloridium`
- `default_template_path() -> Path` – `BLORIDIUM_TEMPLATE` / `webapp/template_waveform.qpat` / `<repo>/docs/refs/qpat/template_waveform.qpat`
- `split_sysex_messages(data: bytes) -> list[bytes]` – splits at F0..F7; without F0 -> `[data]`
- `parse_upload(filename: str, data: bytes) -> dict` – decode `.hex`; per message `blofeld_dump.parse_sndd`, only cmd 0x10; returns `{"sounds": [parsed...], "errors": [{index, error}], "skipped": int}`; chk_ok=False -> errors
- `location_str(bb: int, nn: int) -> str` – like `workflow.location_str`
- `convert_sound(core, template, parsed, loc) -> dict` – `{"loc", "name", "qpat_bytes", "mapped", "unmapped"}`
- `safe_name(name) -> str` – like `workflow.convert_parsed` (alnum/-/_/space)
- `process_upload(filename, data, data_dir) -> dict` – parses, converts, builds the ZIP (BytesIO: `<LOC>_<safe>.qpat` + `MANIFEST.md` + `report.json`) and writes `data_dir/<token>/{result.zip,report.json}`; returns the report incl. `token`, `zip_name`, `sounds: [{location,name,category,mapped,unmapped,score,score_details,features}]`

### Task 2: Deterministic match placeholder (`webapp/matching.py`)

- Test: `tests/test_webapp.py` (tests 4-5)

**Interfaces:**
- `estimate_match(parsed: dict, unmapped: list[str], qm) -> dict` – purely deterministic; returns `{"score": float 0..100 (1 decimal), "parts": {"osc":..,"filter":..,"fx":..,"env_mod":..,"arp":..}, "penalties": [str]}`; weights osc 0.30 / filter 0.25 / fx 0.15 / env_mod 0.20 / arp 0.10; approximations (wavetable without bridge, BP/Notch/Comb filter, triple FX, unmapped mod destinations, arp active) as deductions
