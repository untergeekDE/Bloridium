# `bloridium explore` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Interactive `bloridium explore`: says which Iridium parameter to turn next on the panel, records the OS4 NRPN (pid + value), books it into `docs/midi-maps/iridium_os4_cc_list.csv` + `recordings/explore_log.jsonl` – data basis for an OS4 .mimap and "Iridium as editor for the Blofeld".

**Architecture:** Pure, hardware-free logic in `bloridium/explore.py` (NRPN decoder state machine, CSV state, JSONL log); thin MIDI/prompt layer as `cmd_explore` in `bloridium/cli.py` (uses `midi.DEFAULT_PORTS["iridium"]` + `Synth.receive()`). Read-only – the tool sends no MIDI.

**Tech Stack:** Python ≥ 3.10, mido (existing), pytest; macOS/CoreMIDI. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-12-explore-design.md` (approved 2026-11-12; builder-check decisions see spec "Builder-Check")

## Global Constraints

- Read-only: `explore` sends **no** MIDI (no CC, no PC, no SysEx) – the CC7=0-silence danger is eliminated.
- CSV `iridium_os4_cc_list.csv`: the existing 8 columns stay unchanged, new columns only appended (`NEW_COLUMNS`).
- NRPN decoding: `pid=(cc99<<7)|cc98`, `value=(cc6<<7)|cc38`; `cc99/98=127` and `cc121` reset the state; `cc101/100` (RPN) ignore.
- Strictly filter the channel (default 0-based 5 = ch6 = Part 1, `--channel` override); foreign channels are neither decoded nor booked.
- Exit codes: 0 ok, 1 error, 2 hardware unreachable (port list on stderr) – like the existing CLI.
- Output plain text (German, like the existing CLI), `--json` for `explore --list`.
- No live MIDI in tests (monkeypatch, tmp_path).
- macOS, Python ≥ 3.10; only stdlib + mido + pytest.

## Review Focus

1. **Wrong port/channel → empty captures** (DIN possibly delivers no panel NRPN; part not on ch6): three-level diagnosis on an empty capture (nothing received / only CC / NRPN on another channel with channel hint). Test: `test_explore_empty_capture_hints_and_stays`.
2. **Multiple pids in one capture** (e.g. sound change pid 3113 in the middle of a turn): most frequent pid wins, min/max/last only over the winner, all events into the log. Test: `test_book_row_winner_pid`.
3. **Old CSV without new columns** (before the first run): `load_cc_list` adds empty columns, `save_cc_list` appends + creates `.bak`. Test: `test_csv_roundtrip_appends_columns_and_bak`.
4. **NRPN reset in the middle of the stream** (`cc99/98=127`, `cc121`): must not produce a ghost event. Test: `test_decoder_reset_cases`.
5. **The tool sends nothing** (anti-goal "read-only"): the session must not produce a single out message. Test: `test_explore_session_sends_nothing` (FakeSynth records `send`).
